# 🛡️ PhishGuard AI

**PhishGuard AI** is an AI-powered cybersecurity web application that helps users identify phishing and suspicious websites before they become victims of online scams. Users simply enter a website URL, and the AI analyzes it to determine whether it appears safe or potentially malicious.

## 🚀 Live Demo

🔗 https://phiishguard-ai.netlify.app

---

# 📌 Problem Statement

Phishing attacks are one of the most common cyber threats today. Many users cannot easily distinguish between legitimate and fake websites, leading to stolen passwords, financial loss, and identity theft.

**PhishGuard AI** solves this problem by providing an easy-to-use AI assistant that analyzes suspicious URLs and explains whether a website is safe or potentially dangerous.

**Target Users**

- General internet users
- Students
- Employees
- Freelancers
- Small businesses
- Anyone concerned about online security

# 🤖 AI Feature

The core feature of PhishGuard AI is its intelligent phishing detection assistant.

### What it does

When a user submits a URL, the AI:

- Examines the provided website link
- Detects common phishing indicators
- Identifies suspicious patterns
- Estimates the security risk
- Explains why the website is considered safe or unsafe
- Provides safety recommendations for the user

### System Prompt / AI Instructions

```
You are PhishGuard AI, a cybersecurity assistant specialized in phishing detection.

Your responsibilities are:

- Analyze URLs for phishing indicators.
- Identify suspicious characteristics such as fake domains, misleading branding, unusual URLs, or social engineering tactics.
- Explain your reasoning clearly.
- Classify the URL as:
  • Safe
  • Suspicious

  • Likely Phishing



Always provide practical cybersecurity recommendations.

# ⚙️ How to Run the Project

## Clone Repository

```bash
git clone https://github.com/yourusername/phishguard-ai.git
```

## Navigate to Project

```bash
cd phishguard-ai
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```The application will run locally at:

```
http://localhost:5173
```
